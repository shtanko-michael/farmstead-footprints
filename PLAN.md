# Imprint — план разработки

> Рабочее название. Мод №1 и пилот всего конвейера: на нём обкатываются шаблон, тест-матрица, ассеты, картинки, видео и листинг.

## 1. Концепция и аудитория

Мир запоминает, где по нему ходили. Следы остаются:

- **игроков** — в снегу, песке, грязи, гравии, на снежном покрове;
- **мобов** — у волка лапы, у лошади копыта, у курицы трёхпалые лапки;
- **мокрые** — тёмные отпечатки на камне и досках после воды или дождя, они высыхают.

Часто хоженые места превращаются в **протоптанные тропинки** в траве. Мод чисто клиентский: работает на любом сервере, без установки на сервер. Есть необязательный серверный модуль, который делает тропинки настоящими блоками.

**Аудитория:** все, кто ставит «вау»-моды без шейдеров (Fancy World Animations, Wakes, Effective, Falling Leaves), авторы модпаков в жанре vanilla+ и создатели скриншотов и роликов.

**Почему зайдёт** (анализ 11.11.2026):

- Клиентская «красота» растёт быстрее всего. Fancy World Animations набрал 1,75 млн за 9 месяцев (1 184 подписчика), у Wakes 3 961 подписчик, у Effective — 3 439 при 3,4 млн скачиваний.
- Ниша почти пуста: Footprint Particles — 81 тыс. скачиваний, DarkSteps — 651. Звуки шагов делает Presence Footsteps (41,4 млн), но видимых следов он не рисует — это естественная пара.
- Декор попадает в топ в 1,3 раза чаще среднего по Modrinth (16,8 против 12,7 на 1000 модов).

## 2. Функции

### MVP

- Отпечатки игроков на песке, красном песке, снегу (блок и слой), грязи, гравии, глине, почве и песке душ.
- Левая и правая нога по фазе шага. Глубина и время жизни зависят от поверхности, отпечатки плавно затухают.
- Цвет отпечатка берётся из средней тени текстуры блока, поэтому работает с ресурспаками и модовыми блоками.
- Пул декалей с бюджетом и отсечением по дистанции и фрустуму.

### 1.0

- **Следы мобов** по профилям: гуманоид, лапа (волк, кошка, лиса), копыто (лошадь, корова, свинья, овца), птичья лапа, большой след (железный голем, равагер), «нет следов» (летающие, призраки).
- **Мокрые следы:** после воды, дождя или снега на твёрдых поверхностях. Высыхают быстрее на солнце и у огня, в дождь не появляются.
- **Протоптанные тропинки:** клиентская тепловая карта шагов по траве. Трава визуально «стирается» в три стадии. Кэш хранится на диск отдельно для каждого мира и сервера.
- **Снегопад** заметает следы быстрее, ветер в пустыне — тоже.
- **Подкат при приземлении с элитрой** и вмятина от падения с высоты.
- **Data-driven поверхности и профили сущностей:** JSON в ресурспаке. Модпакеры добавляют свои блоки и мобов без кода.
- **Необязательный серверный модуль:** трава → грубая земля → тропа после N проходов, затухание без хождения. Включается только в серверном конфиге.

### После 1.0

- Колея от вагонеток и лодок на берегу, следы на ковровом снегу из модов (Snow! Real Magic).
- API для других модов: «оставь след такого-то профиля здесь».
- Следы на мелководье (рябь) — согласовать с Wakes.

## 3. Платформы

| MC | Лоадеры | Примечание |
| --- | --- | --- |
| 1.20.1 | Forge, Fabric | Старый рендер-пайплайн (VertexFormat до 1.21) |
| 1.21.1 | NeoForge, Fabric | Основная цель, на ней снимаем видео |
| 26.x (26.3) | NeoForge, Fabric | Новый рендер-пайплайн (RenderPipeline / GpuDevice) — самый большой риск |

- Сторона: клиент. Серверный модуль — тот же jar, включается, только если мод стоит на сервере.
- Обязательных зависимостей нет. Необязательные: Mod Menu + YACL на Fabric (экран настроек), Sodium и Iris (совместимость).

## 4. Архитектура

- **`common/step`** — детектор шагов. Для каждой видимой живой сущности берёт фазу `walkAnimation` и дельту позиции, выдаёт событие `Step(entity, foot, pos, yaw, speed)`. Учитывает присед, бег, плавание, езду (у всадника следов нет, есть у маунта).
- **`common/surface`** — реестр поверхностей из JSON. Блок-теги → стиль, глубина, время жизни, «мокрость», влияние погоды. Модовые блоки подхватываются через теги, в том числе `c:` и `forge:`.
- **`common/decal`** — пул декалей фиксированного размера (кольцевой буфер). Хранятся позиция, поворот, маска, цвет, время рождения и стадия затухания. Есть пространственный индекс по секциям чанка. Декали на выгруженных чанках удаляются.
- **`common/render`** — пакетный рендер всех декалей одним вызовом на кадр. Квады чуть выше верхней грани блока, повторяют уклон слоя снега и плит, своя `RenderType` (translucent, без записи глубины).
  - Stonecutter-ветки для 1.20.1 / 1.21.1 / 26.x.
  - Хук рендера: Fabric — `WorldRenderEvents.AFTER_ENTITIES`; NeoForge/Forge — `RenderLevelStageEvent` (AFTER_ENTITIES / AFTER_TRANSLUCENT_BLOCKS). Выбор стадии проверяется с Iris.
- **`common/trails`** — тепловая карта по блокам, сжатая в регионы 32×32. Overlay-текстура стёртой травы рисуется тем же декальным рендером. Сохраняется в `imprint/trails/<server-or-world>.bin`.
- **`common/server`** — серверный модуль тропинок, тот же счётчик на сервере, превращение блоков. Работает только при `server.trails.convertBlocks = true`.
- **Платформенные сервисы:** события рендера и тика клиента, загрузка ресурсов (reload listener), конфиг, права (только для серверного модуля), регистрация команд.
- **Миксины** — минимум: доступ к фазе шага, если её нет в API. Всё остальное делается через события.

## 5. Конфиг

### `imprint-client.toml`

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `preset` | `default` | `vanilla_plus` / `default` / `cinematic` / `performance` |
| `enabled` | true | Общий выключатель |
| `footprints.players` / `footprints.mobs` / `footprints.self` | true / true / true | Чьи следы рисовать (`self` — свои в первом лице) |
| `footprints.maxDecals` | 2048 (64–16384) | Бюджет декалей |
| `footprints.renderDistance` | 48 блоков (8–128) | Дальность отрисовки |
| `footprints.lifetimeMultiplier` | 1.0 (0.1–10) | Множитель времени жизни |
| `footprints.opacity` | 0.85 | Непрозрачность |
| `footprints.entityBlacklist` | [] | Сущности без следов |
| `wet.enabled`, `wet.dryingSpeed` | true, 1.0 | Мокрые следы |
| `trails.enabled`, `trails.threshold`, `trails.decayDays` | true, 40, 7 | Визуальные тропинки |
| `weather.snowFillsPrints` | true | Снегопад заметает следы |
| `debug.showStats` | false | Число декалей и время кадра в F3 |

### `imprint-server.toml` (модуль тропинок)

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `trails.convertBlocks` | false | Включить настоящие тропинки |
| `trails.stages` | `grass_block → coarse_dirt → dirt_path` | Стадии превращения |
| `trails.stepsPerStage` | 60 | Шагов до следующей стадии |
| `trails.decayDays` | 10 | Затухание без хождения |
| `trails.dimensions` | `minecraft:overworld` | Где работает |
| `trails.respectClaims` | true | Проверять право ломать блок через событие |

Пресеты меняют `maxDecals`, `lifetimeMultiplier`, `renderDistance` и включённые функции одной строкой. Экран настроек в игре группирует ключи так же, как файл.

## 6. Права (LuckPerms)

Права нужны только серверному модулю. Клиентская часть ничего не проверяет.

| Узел | По умолчанию | Что даёт |
| --- | --- | --- |
| `imprint.trails.contribute` | true | Шаги игрока протаптывают настоящую тропу |
| `imprint.command.reload` | op | `/imprint reload` |
| `imprint.command.clear` | op | `/imprint trails clear <radius>` — стереть счётчики |
| `imprint.command.stats` | op | `/imprint trails stats` |

| Meta | По умолчанию | Что задаёт |
| --- | --- | --- |
| `imprint.trails.weight` | 1.0 | Вес шага игрока (VIP и лошади протаптывают быстрее) |

## 7. Локализация

- Около 70 ключей: экран настроек и подсказки, имена пресетов, сообщения команд, комментарии конфига.
- Термины для переводчика: «след/отпечаток» (footprint), «тропа» (trail, не «путь»), «мокрый след» (wet print).

## 8. Ассеты

Маски — 32×32, оттенки серого с альфой. Цвет даёт поверхность.

| Ассет | Кол-во | Способ |
| --- | --- | --- |
| Ботинок L/R (2 вариации протектора) | 4 | Codex-эскиз → порог → маска 32×32, ручная правка |
| Босая нога (для мобов-гуманоидов без брони) | 2 | то же |
| Лапа (волк/лиса/кошка — масштаб) | 2 | то же |
| Копыто | 2 | то же |
| Птичья лапа | 1 | то же |
| Большой след (голем, равагер) | 2 | то же |
| Стёртая трава, 3 стадии (tileable 16×16) | 3 | Codex-эскиз → проекция на 16×16, палитра ванильной травы |
| Мокрая маска (размытие + блик) | 1 | процедурно |
| Иконка мода 512, логотип | 2 | Codex + ручная доводка |

Звуков нет: звуки шагов остаются за ванилой или Presence Footsteps.

## 9. Совместимость

**Обязательно проверить:**

- Sodium + Iris с шейдерпаками Complementary Reimagined, BSL, Bliss — на 1.21.1 и 26.x;
- Embeddium + Oculus на Forge 1.20.1;
- Distant Horizons — на LOD следов нет, без артефактов;
- Presence Footsteps — синхронность шага;
- Snow! Real Magic / Snow Under Trees — слой снега;
- Terralith и Tectonic — поверхности;
- Fancy World Animations, Wakes, Particle Rain — без конфликтов;
- сервер без мода — клиент работает молча.

**Модовые блоки:** проверить, что теги `c:sands`, `c:gravels`, `c:snow` подхватываются.

## 10. Тест-план

**Автоматически (`farmstead-mod-tools/test-matrix`):**

- Юнит-тесты: детектор шагов (фазы, присед, бег), пул декалей (вытеснение, бюджет), парсер JSON поверхностей.
- На каждой из шести целей:
  1. Клиент заходит на dev-сервер по quickPlay.
  2. RCON телепортирует игрока по прямой по песку, снегу и траве (серия `/tp` с шагом 0,3 блока).
  3. Делается скриншот.
  4. Проверка: в логе нет ошибок, F3-статистика показывает больше 0 декалей.
- Серверный модуль, GameTest: после 60 шагов `grass_block` → `coarse_dirt`; с `imprint.trails.contribute = false` блок не меняется; `imprint.trails.weight = 2` даёт стадию вдвое быстрее.
- **Производительность:** бенчмарк-мир — загон со 100 жителями и 30 волками. Время кадра с модом и без, на Sodium, на 1.21.1. Цель — ≤ 0,3 мс на кадр на `default`, ≤ 0,1 мс на `performance`.

**Вручную (скриншоты в чат):**

- Пляж, снежная тайга, болото, деревня с тропинками, переход реки → камень (мокрые следы);
- с шейдерами и без; ночь и день.

## 11. Презентация

- **Анимированная заставка** (GIF/WebP, 6 с, цикл): игрок бежит по снежному склону на закате, за ним тянутся следы, камера отъезжает, проявляется логотип «Imprint — the world remembers your steps».
- **GIF функций (≤ 5 с каждый):**
  - стая волков по снегу;
  - тропинка проявляется за «неделю» (таймлапс);
  - мокрые следы от реки до каменного дома;
  - следы лошади на пляже;
  - снегопад заметает след.
- **Галерея (8 кадров):** пляж на рассвете, тайга, деревня с тропинками, болото, пустыня, «до/после» с шейдерами, экран настроек, слайд «Works on Fabric · NeoForge · Forge».
- **Видео 45 с:**
  1. 0–5 с — хук (следы за бегущим игроком);
  2. 5–30 с — пять поверхностей и мобы;
  3. 30–40 с — тропинки и мокрые следы;
  4. 40–45 с — логотип, лоадеры, версии.
  Музыка — спокойный эмбиент (ElevenLabs).
- **Тезисы описания:** «Client-side, works on any server», «No shaders needed, shader-friendly», «Data-driven: add your own blocks and mobs», «Pairs perfectly with Presence Footsteps».

## 12. Вехи и риски

| Веха | Содержание |
| --- | --- |
| M0 | Шаблон + тест-матрица на «hello world» (Фаза 0, вместе с Imprint) |
| M1 | Следы игрока на песке и снегу, пул и рендер, NeoForge + Fabric 1.21.1 |
| M2 | Data-driven поверхности, мобы, конфиг, экран настроек, 12 языков |
| M3 | Мокрые следы, тропинки (клиент + серверный модуль), права |
| M4 | Порты 1.20.1 (Forge/Fabric) и 26.x (NeoForge/Fabric), прогон совместимости |
| M5 | Ассеты финальные, бенчмарк, заставка, GIF, галерея, видео, документация, листинг |

| Риск | Что делаем |
| --- | --- |
| Новый рендер-пайплайн 26.x несовместим с подходом 1.21.1 | Своя абстракция `DecalRenderer` с тремя реализациями; 26.x — отдельная ветка Stonecutter; при блокере 26.x выходит в 1.1 |
| Iris рисует декали не в том проходе или без теней | Выбор стадии рендера под Iris, проверка с тремя шейдерпаками, опция «рисовать в translucent-проходе» |
| Z-fighting на неровных блоках | Смещение по нормали + polygon offset, отдельная логика для слоёв снега и плит |
| Производительность в больших толпах | Бюджет на чанк, LOD (дальние следы — без затухания-анимации), пресет `performance` |
| Детектор шагов «стреляет» не в такт звуку | Сверка с Presence Footsteps; синхронизация с моментом звука шага ванилы |
